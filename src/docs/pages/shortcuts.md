Keyboard shortcuts are the fastest way to move around Dexter Write. Use the command palette when you do not remember a control.

## Global

| Shortcut | Action |
|---|---|
| `Ctrl/Cmd + K` | Open the command palette |
| `Ctrl/Cmd + S` | Save the project locally |
| `Ctrl/Cmd + P` | Print or export as PDF |
| `Ctrl/Cmd + F` | Find and replace in the active document |
| `Ctrl/Cmd + Z` | Undo the editor or applied AI change |
| `Ctrl/Cmd + Enter` | Recompile when focus is outside an input |
| `Esc` | Close the topmost dialog |

## Layout

| Control | Action |
|---|---|
| Code / Split / Preview | Switch the center layout |
| Pane maximize | Expand one pane |
| Pane close | Hide a pane |
| Edge rails | Reopen a hidden pane |
| Double-click divider | Reset pane sizes |

The mobile view switcher uses Editor, Preview, and Panel instead of the desktop split controls.

## AI Playground

| Shortcut | Action |
|---|---|
| `Enter` | Send the prompt |
| `Ctrl/Cmd + Enter` | Insert a newline in the prompt |
| `Esc` | Close the active dialog or menu |

Use the review controls to apply or discard a proposed change. The toolbar **Undo AI** action reverses the last applied AI action.

## Preview

| Shortcut | Action |
|---|---|
| `Ctrl/Cmd + Enter` | Recompile |
| Double-click preview line | Inverse search to the source line |
| Preview toolbar | Zoom, reset, download, external preview, maximize, hide |

Inverse search depends on the document engine and the source map.

## Command palette

The palette can open files, switch layout presets, toggle the theme, export, validate, start live collaboration, and run document actions. It is the single place to discover an action you cannot find in the toolbar.

## Accessibility

- Focus rings are visible on keyboard navigation.
- Dialogs close with **Esc**.
- The toolbar and activity rail expose labels for icon-only controls.
- The docs page search supports `/` and `Ctrl/Cmd + K`, and **Esc** clears it.
